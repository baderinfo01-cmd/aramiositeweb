# Aramio Smart Global Academy — موقع أكاديمية أراميو

موقع أكاديمية تدريبية (PHP + MySQL/MariaDB) مع ثلاث لوحات (أدمن / مدرب / متدرب)، 6 لغات، ومنصة ذكاء اصطناعي مستقلة عن المزوّد.

📘 **دليل التشغيل المحلي والرفع على الاستضافة والأمان: [`docs/LOCAL_AND_DEPLOY_AR.md`](docs/LOCAL_AND_DEPLOY_AR.md)**

- الكود في `public_html/` · ترقية القاعدة في `database/upgrade_v2.sql` · أدوات في `tools/`
- لا ترفع أبدًا `includes/config.local.php` ولا ملفات `.sql` ولا مجلد `uploads/` إلى GitHub (مستثناة في `.gitignore`).
